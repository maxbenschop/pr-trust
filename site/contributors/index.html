What the three labels mean

trust: admitted

The project trusts the account: a maintainer vouched for it here, a project this one trusts vouched for it, or it already has merged work the project counts.

Reviewed like any other pull request.

trust: unknownYou are here

The account is on none of the project's lists. It is the starting point for every new contributor, not a verdict.

Stays open with the label. A few projects close unknown pull requests. If this one does, the bot's comment says so.

trust: denounced

This project's own list has blocked the account, usually after spam or abuse.

Usually closed. Only this project's maintainers can lift it.

How to get vouched

It usually takes one short message and a maintainer saying yes. You do not need to open your pull request again.

First, check whether you already are.

Run the same check against your pull request with the project's current rules. It only reads, and needs Node 22.18 or later and a GitHub login (gh auth login). If it says admitted, mention that on your pull request.

npx github:maxbenschop/pr-trust check owner/repo#123
owner/repo#123 by your-username
Result: admitted (vouched in this project's own list)

Introduce yourself.

Reply on your pull request. Say what you are fixing and why you ran into it. Two honest sentences are enough. You can start from this:

Hi, I'm [your name]. I opened this because [what broke for you, or what you needed]. I tested it by [how]. Happy to adjust anything.

A maintainer vouches for you.

They add your username to the project's VOUCHED.td and re-run the check. The label switches to trust: admitted and every pull request you open after that is admitted too, as it is in any project that accepts this project's list.

If the label says denounced and you think that is wrong

Only a project's own list can denounce an account, so the entry is in the VOUCHED.td of the project you sent your pull request to, and only its maintainers can change it. Open an issue or contact a maintainer, explain what happened, and ask them to remove the line. Lists shared from other projects can never block you.
